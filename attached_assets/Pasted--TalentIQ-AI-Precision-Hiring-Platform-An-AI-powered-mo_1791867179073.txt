## Overview

**TalentIQ AI** is a full-stack mobile application that reimagines the hiring process. Built for both **Job Seekers** and **HR Professionals**, it uses generative AI to:

- **Match candidates** to job postings with a precise score
- **Identify skill gaps** between a candidate's resume and a job's requirements
- **Generate intelligent assessments** (MCQ / Aptitude / Coding) tailored per role
- **Monitor assessment integrity** with proctoring metadata
- **Provide an HR overview** of open roles, candidate pipelines, and top matches

The project is a **monorepo** containing two sub-packages:

| Package | Description |
|---|---|
| `mobile/` | React Native (Expo) cross-platform app |
| `server/` | Node.js + Express REST API |

## Features

### 👤 Job Seekers
- 📝 **Profile & Resume Builder** — upload resume PDF, list skills, experience, education
- 🔍 **Job Discovery** — browse and search active job listings
- 📊 **AI Match Score** — see a numerical match score against any job
- 🔬 **Skill Gap Analysis** — AI identifies your strengths vs. missing skills
- 📋 **Application Tracker** — view all your applications with live status (`APPLIED → SHORTLISTED → HIRED/REJECTED`)
- 🧪 **Smart Assessments** — take AI-generated MCQ/Aptitude/Coding tests per role

### 🏢 HR Professionals
- 📈 **HR Dashboard** — overview of open roles, top matches, total applicants
- 🗂️ **Active Pipelines** — per-job candidate funnel visualization
- 🤖 **AI Recommendations** — auto-ranked candidate shortlists
- ✅ **Assessment Management** — create, assign, and review assessments
- 🔒 **Integrity Monitoring** — log focus-loss, background switches, and network events during assessments

### 🛡️ Authentication
- Role-based access (`JOB_SEEKER`, `HR`, `ADMIN`)
- JWT token authentication with auto-routing on app open
- Password hashing with bcryptjs

## Getting Started

### Prerequisites

Ensure you have the following installed:

| Tool | Version | Notes |
|---|---|---|
| Node.js | ≥ 20.x | [Download](https://nodejs.org) |
| npm | ≥ 10.x | Bundled with Node |
| Expo CLI | Latest | `npm install -g expo-cli` |
| Android Studio | Latest | For Android emulator |
| MongoDB Atlas account | — | Free tier works |
| OpenAI API Key | — | For AI features (optional — has fallback) |

---

### Environment Setup

Create or update `server/.env`:

```env
PORT=5001
DATABASE_URL="mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/talentiq?appName=Cluster0"
JWT_SECRET="your_super_secret_jwt_key"
OPENAI_API_KEY="sk-..."       # Optional: AI falls back to mock data if missing
```

> [!NOTE]
> The AI service gracefully falls back to mock assessment questions if no valid API key is provided, so the app is fully functional without an OpenAI key during development.

### Running the Project

#### ⚡ One-click start (Windows)

```bat
./start.bat
```

This opens two terminal windows — one for the backend, one for the mobile app.

---

#### Manual Start

**Backend Server:**
```bash
cd server
npm install
npm run build    # Generates Prisma client + compiles TypeScript
npm run dev      # Starts tsx watch mode on port 5001
```

**Mobile App:**
```bash
cd mobile
npm install
npx expo start   # Opens Expo Dev Tools
```

Then press:
- `a` — run on Android emulator
- `i` — run on iOS simulator (macOS only)
- `w` — run in browser (web mode)

> [!TIP]
> Use the **Expo Go** app on your physical device and scan the QR code for the fastest development experience.

## API Reference

All routes are prefixed with `/api`. Protected routes require `Authorization: Bearer <token>`.

### Auth — `/api/auth`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| POST | `/register` | ❌ | Register a new user |
| POST | `/login` | ❌ | Login and receive JWT |

### Jobs — `/api/jobs`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| GET | `/` | ✅ | List all active jobs |
| GET | `/:id` | ✅ | Get job details |
| POST | `/` | ✅ HR | Create a job posting |

### Profile — `/api/profile`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| GET | `/` | ✅ | Get current user's profile |
| POST | `/` | ✅ | Create or update profile |
| POST | `/resume` | ✅ | Upload resume PDF (multipart) |

### HR — `/api/hr`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| GET | `/dashboard` | ✅ HR | Overview stats (roles, matches) |
| GET | `/applicants/:jobId` | ✅ HR | Get applicants for a job |

### AI — `/api/ai`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| GET | `/match/:jobId` | ✅ | AI match score & gap analysis for current user vs job |

### Assessments — `/api/assessment`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| GET | `/:jobId` | ✅ | Get assessment for a job |
| POST | `/generate` | ✅ HR | AI-generate assessment questions |
| POST | `/:id/submit` | ✅ | Submit answers & receive score |

### Health Check

```
GET /api/health

```

## Database Schema

Built with **Prisma ORM** targeting **MongoDB Atlas**.

```
User ─── Profile (1:1)
User ─── Application[] (1:N)
User ─── AssessmentAttempt[] (1:N)
User ─── Company? (via companyId)

Company ─── Job[] (1:N)
Company ─── User[] (recruiters)

Job ─── Application[] (1:N)
Job ─── Assessment[] (1:N)

Assessment ─── AssessmentAttempt[] (1:N)
```

### Key Models

| Model | Key Fields |
|---|---|
| `User` | email, password, name, role (`JOB_SEEKER` / `HR` / `ADMIN`) |
| `Profile` | resumeUrl, skills[], experience, education, aiSummary |
| `Job` | title, description, requirements[], skills[], type, isActive |
| `Application` | status, matchScore, skillMatch, experienceMatch, aiRecommendations |
| `Assessment` | type (`MCQ`/`CODING`/`APTITUDE`), questions (JSON), duration |
| `AssessmentAttempt` | score, integrityScore, integrityLogs (focus-loss events) |

## AI Capabilities

### 1. AI Match Scoring (`/api/ai/match/:jobId`)

When called, the AI engine:
1. Fetches the candidate's profile (skills, experience, resume summary)
2. Fetches the job's required skills and description
3. Calls the LLM to return a structured JSON with:
   - `matchScore` (0–100)
   - `strengths[]` — skills the candidate already has
   - `missingSkills[]` — skill gaps to address
   - `recommendation` — a written paragraph of personalised advice

### 2. Assessment Generation (`/api/assessment/generate`)

The AI generates role-specific questions using Zod schema enforcement:
```typescript
z.object({
  questions: z.array(z.object({
    prompt: z.string(),
    options: z.array(z.string()).optional(),
    correctAnswer: z.string(),
    difficulty: z.enum(["Easy", "Medium", "Hard"])
  }))
})
```

> [!IMPORTANT]
> To swap from OpenAI to Google Gemini, change one line in `server/src/services/aiService.ts`:
> ```ts
> // From:
> model: openai('gpt-4o-mini'),
> // To:
> model: google('gemini-1.5-flash'),
> ```
